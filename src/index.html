Hvor grønn er din kommunes nettside?

English version

Hva?

Prosjektet Grønne kommuner har som mål å vise hvordan en nettsides størrelse i kilobytes og megabytes påvirker karbonfotavtrykket. Vi ønsker å vise hvor mange karbondioksidekvivalenter (CO2e) som slippes ut når man åpner hver av de norske kommunenes nettsider, og vi ønsker å tilby tips og triks for å redusere utslippene hver besøkende produserer.

Hvordan?

Tallene på denne siden beregnes ved å laste ned hver kommunes forside og filene siden laster inn (CSS, JavaScript, bilder og lignende) for å måle hvor mange bytes som overføres. Deretter sjekker vi om nettsiden er hostet på fornybar strøm via The Green Web Foundation, og til slutt estimerer vi CO2-utslippet med Sustainable Web Design-modellen gjennom det åpne biblioteket CO2.js. Som du kan se nedenfor, slipper ikke hvert sidebesøk ut veldig mange gram CO2, men disse nettsidene får bare en liten del av verdens sidevisninger, så i sum kan vi se at det blir en del.

Den gjennomsnittlige nettsiden produserer omtrent 1,76 gram CO 2 per sidevisning ifølge Sustainable Web Design-modellen. For en nettside med 10 000 månedlige sidevisninger blir det 211 kg CO 2 per år.
— Sustainable Web Design-modellen

Hvorfor?

Norske kommuner er valgt fordi vi mener offentlige tjenester bør være forbilder, og fordi det er over 300 av dem som er svært like i innhold.

Hva hjelper?

Vi kan optimalisere bilder ved å skalere dem ned til akkurat så store som vi trenger dem, og det finnes mange teknikker for å gjøre en nettsides kodebase mindre.

Ser du din nettside på listen og ønsker å forbedre den? Foreløpig, vær så snill å ta kontakt med oss ved å opprette en issue på GitHub, enten på engelsk eller på norsk.

Hvordan kan jeg delta?

Dette prosjektet er fortsatt under utvikling og kan følges på GitHub. Bidrag er velkomne.
