How green is your municipality's website?

Norwegian version

What?

The Green municipalities project aims to show how a website's size in kilobytes and megabytes affects its carbon footprint. We want to show how many carbon dioxide equivalents are emitted by opening each of the Norwegian municipalities' websites, and we want to offer tips and tricks for decreasing the emissions each visitor produces.

How?

The numbers on this page are estimated by downloading each municipality's front page and the files it loads (CSS, JavaScript, images, etc.) to measure how many bytes are transferred. We then check whether the website is hosted on renewable electricity via The Green Web Foundation, and finally estimate the CO2 emissions with the Sustainable Web Design model using the open-source CO2.js library. As can be seen below, each page view does not emit very many grams of CO2, however these websites only get a tiny portion of the page views of the world, so it definitely adds up.

The average web page produces approximately 1.76 grams CO2 per page view according to the Sustainable Web Design model. For a website with 10,000 monthly page views, that's 211 kg CO2 per year.
— Sustainable Web Design model

Why?

Norwegian municipalities have been chosen because we think public services should be role models, and because there are more than 300 of them which are highly similar in contents.

What helps?

We can optimize images by scaling them down to just as big as we need them, and there are many techniques to make a website's code base smaller.

Do you see your website on the list and you want to improve? For now, please reach out to us by creating an issue on GitHub, either in English or Norwegian.

How can I take part?

This project is still in development and can be followed on GitHub. Contributions are welcome.
